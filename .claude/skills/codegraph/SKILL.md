# CodeGraph for the OSF drone simulator

The project is indexed with **CodeGraph** (`@colbymchenry/codegraph`, MIT, 100 % local SQLite index in `.codegraph/`, git-ignored, auto-synced on file changes). Telemetry is turned off (`codegraph telemetry off`).

## When to use
- "Where is X defined / who calls X / what breaks if I change X" → CodeGraph first, then open only the files it points to.
- Before editing a shared piece (`src/data/world.ts` live bindings, `scripts/gen-layout.mjs` layout, `src/sim/engine.ts`, `src/main.ts` nav/router), run `impact` to see every dependant.

## How
- **MCP (preferred in Claude Code):** the project `.mcp.json` starts `codegraph serve --mcp`; use the `codegraph_explore` tool (approve it once when Claude Code asks).
- **CLI (Bash):**
  ```bash
  codegraph status                 # index health
  codegraph query <text>           # find symbols
  codegraph explore "<question>"   # symbols + call paths for a question
  codegraph callers <symbol>       # who calls it      e.g. codegraph callers startLesson
  codegraph impact <symbol>        # what depends on it
  codegraph sync                   # incremental re-index (normally automatic)
  codegraph index                  # full rebuild (after big refactors / branch switches)
  ```
- First time on a new machine: `npm i -g @colbymchenry/codegraph`, then `codegraph init` in the project root.

## Project map hints (pair with AGENTS.md)
- Physics/FC: `assembly/index.ts` (AssemblyScript → `public/sim.wasm`); layout is generated by `scripts/gen-layout.mjs`.
- Runtime: `src/sim/engine.ts` → `src/main.ts` (nav + router in `src/ui/router.ts`).
- Lessons: `src/lessons/lessons.ts` (advanced) + `src/lessons/basics.ts` (beginner 1–10 with demo autopilot).
- Course: `src/course/*`, `src/ui/course.ts`, content in `content/course/`.
- Server: `server.mjs`, `server-live.mjs`, `src/server/*`, `src/app/api/*`.

## Rules
- CodeGraph answers are a map, not the truth: open the file before editing.
- Never commit `.codegraph/`.
